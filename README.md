# TourUZ Dashboard — B2B Agency CRM & Extranet

B2B-портал и CRM-система для туроператоров и турагентств платформы **TourUZ**.

## Возможности
- 📊 **Аналитический Дашборд:** KPI метрики (активные туры, входящие заявки, просмотры витрины, выручка по подтверждённым броням), воронка продаж и топ популярных туров.
- 📋 **CRM Заявок (Воронка лидов):** Канбан-доска и табличный режим работы с клиентскими заявками («В 1 клик» с сайта `TourUZ`), смена статусов, заметки менеджера, быстрый переход в Telegram и звонок клиенту.
- 🏖️ **Extranet Склад туров:** управление турами агентства, быстрое изменение цен с сохранением истории (`PriceHistory`), переключение видимости на витрине и статуса «Горящий тур 🔥», добавление и редактирование туров.
- 🏢 **Мульти-агентский режим:** переключение между сводным режимом Супер-администратора и кабинетом любого из 27 верифицированных туроператоров Узбекистана.

## Локальный запуск
```bash
npm install
npm run dev
```
Приложение запускается на [http://localhost:3003](http://localhost:3003) и подключается к единому API `http://localhost:8000/api/v1`.
